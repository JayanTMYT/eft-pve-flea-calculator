# Flea Ledger

An Escape from Tarkov **PVE flea-market calculator** that finds the listing price with the highest net proceeds after fees.

## How to use

1. Select your **Intelligence Centre level** (0–3).
2. Search for an item, then enter the **quantity** and **listing price per item**.
3. Review the listing fee, net proceeds and suggested best price. Adjust the search range if needed.
4. Save listings to compare different prices side by side.

If an item is missing, choose **Add item** and enter its name and base price. If the base price is unknown, enter known listing prices and fees, then choose **Infer base price**.

Custom items and base-price corrections are remembered in your browser. They do not sync between devices.

**Used keys and keycards have higher listing fees.** Check the in-game fee before listing one.
